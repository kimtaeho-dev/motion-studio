# Motion Studio 디자인 시스템

2026년 10월 리브랜딩 기준. 앱 UI(`src/`)와 브랜드 자산(아이콘, README)에 적용한다.
필름(`films/`)과 렌더 엔진(`lib/`)은 대상이 아니다. 필름의 룩은 `CLAUDE.md`를 따른다.

토큰 값은 `docs/design-tokens.css`에 있고, 실제로는 `src/index.css`의 `:root`·`.dark`에 들어간다.

---

## 1. 원칙

1. **화면은 영상을 위한 무대다.** UI 크롬은 따뜻한 무채색(stone)으로 물러나고, 색은 필름이 가진다.
2. **빨강은 '지금'만 가리킨다.** 재생 헤드와 진행 중인 렌더에만 쓴다. 버튼, 링크, 선택 상태에는 쓰지 않는다.
3. **숫자와 시간은 모노.** 타임코드, 프레임·비트 번호, 수치 입력, 단축키는 Geist Mono로 쓴다.

---

## 2. 로고

마크는 타임라인의 재생 헤드다. 오각형 헤드와 줄기 하나로 되어 있다.

| 파일 | 용도 |
| --- | --- |
| `build/icon.svg` | 앱 아이콘. macOS 그리드, 플레이트 824 / 1024, 모서리 186 |
| `assets/brand/favicon.svg` | 16–32px. 플레이트가 꽉 차고 줄기가 더 굵다 |
| `assets/brand/mark.svg` | 플레이트 없는 마크. `currentColor` |
| `assets/brand/wordmark.svg` | `MOT▾ON STUDIO`. Geist Mono, 자간 0.1em, 아웃라인. I 자리가 재생 헤드(브랜드 빨강), 글자는 `currentColor` |
| `assets/brand/wordmark-dark.svg` | 어두운 바탕용 워드마크. 글자가 stone-100 `#F5F5F4`로 고정. `<img>`는 `currentColor`를 물려받지 못해서 README의 다크 모드(`<picture>`)에 쓴다 |

**아이콘 구성.** 헤드 폭 224, 줄기 56. 마크는 헤드가 무거워 보이는 만큼 플레이트 중심보다 16 아래에 둔다.

**허용 조합**

| 배경 | 마크 |
| --- | --- |
| 브랜드 빨강 `#E5383B` | 흰색 (기본 앱 아이콘) |
| stone-900 `#1C1917` | 브랜드 빨강 |
| paper `#F3F1EC` | 브랜드 빨강 |
| 흰색 | stone-900 (단색, 인쇄) |

**여백과 크기**

- 여백은 사방으로 헤드 폭의 절반 이상.
- 마크만 쓸 때 최소 높이는 12px. 16px 아래에서 아이콘이 필요하면 `favicon.svg`를 쓴다.
- 워드마크의 최소 높이는 10px.

**하지 말 것:** 회전·기울이기·늘리기, 그림자나 그라데이션, 위 조합에 없는 색, 재생 헤드를 다른 글자 자리로 옮기기, 워드마크를 다른 서체로 다시 조판하기.

### 3.3 빨강 규칙

- 브랜드 빨강을 쓰는 곳: 재생 헤드(선, 헤드, 시각 라벨), 진행 중인 렌더·내보내기의 진행 막대와 스피너, 앱 아이콘과 워드마크. 여기까지만 쓴다.
- 쓰지 않는 곳: 버튼 배경, 링크, 체크·라디오·스위치, 선택된 행, 포커스 링, 배지.
- `--brand`(`#E5383B`)는 흰 배경에서 대비가 4.2:1이라 **글자색으로 쓰지 않는다.** 빨강 면 위에 흰 글자를 올릴 때는 `--brand-strong`을 쓴다.
- 삭제·오류는 `--destructive`로 쓰고, 항상 글자나 아이콘(휴지통, 경고)과 같이 둔다. 화면에 빨강이 둘 이상 보여도 "지금"과 "위험"이 헷갈리지 않게 하려는 것이다.

## 4. 타이포그래피

| 역할 | 서체 | 굵기 | 비고 |
| --- | --- | --- | --- |
| UI 전반 | Pretendard | 400 / 500 / 600 | 기존 그대로. 강조는 600(`font-strong`) |
| 숫자·시간 | Geist Mono | 400 | 타임코드(`00:04.12`), 프레임·비트 번호, 수치 입력, 헥스 값, 단축키 표시 |
| 워드마크 | Geist Mono | 400, 대문자, 자간 0.1em | 직접 조판하지 말고 `wordmark.svg`를 쓴다 |

- 크기는 지금 단계를 유지한다: `text-xxs`(11), `text-xs`(12), `text-sm`(14).
- 숫자 열이 흔들리지 않도록 숫자에는 `tabular-nums`를 같이 쓴다.
- 한글 라벨은 대문자·자간 처리를 하지 않는다. 모노 대문자는 영문 짧은 라벨(예: `FPS`, `BPM`)에만 쓴다.

---

## 5. 형태

- **모서리:** 지금 스케일(`--radius-sm` 4 ~ `--radius-4xl` 16)을 유지한다. 컨트롤 6, 카드·다이얼로그 12.
- **테두리:** 1px `--border`. 패널은 테두리나 바탕색 중 하나로만 구분하고 둘을 겹치지 않는다.
- **그림자:** 떠 있는 요소(메뉴, 팝오버, 다이얼로그)에만 쓴다. 패널과 카드에는 쓰지 않는다.
- **아이콘:** `lucide-solid`, 기본 16px(`size-4`). 색은 글자색을 따른다.

---

## 6. 움직임 (앱 UI)

- 시간은 100–200ms, 이징은 `cubic-bezier(0.22, 1, 0.36, 1)`(ease-out).
- 튀는 이징(overshoot)이나 글로우는 쓰지 않는다.
- **재생 헤드에는 이징을 넣지 않는다.** 시간 그 자체라서 선형으로 움직인다.
- `prefers-reduced-motion`이면 등장 애니메이션을 끈다.

## 7. 컴포넌트 규칙

**버튼**

- `default`: `bg-primary text-primary-foreground`. 한 영역에 하나만 둔다(승인, 내보내기, 보내기).
- `secondary` / `outline` / `ghost`: 나머지 동작.
- `destructive`: 지금처럼 옅은 바탕에 빨강 글자. 단독으로 쓰지 말고 확인 대화상자로 이어지게 한다.
- `link`: `text-foreground` + 밑줄. 파랑 링크를 쓰지 않는다.

**메뉴·목록 항목:** hover와 focus는 `bg-accent text-foreground`. 강한 면색(`bg-primary`)을 쓰지 않는다. 선택된 항목은 체크 아이콘으로 표시한다.

**입력:** 테두리 `--border-input`, 포커스는 `--ring` 안쪽 1px(지금 방식 그대로). 오류는 `--destructive` 테두리와 설명 글자.

**체크박스·라디오·스위치·슬라이더:** 켜짐은 `--primary`. 브라우저 기본 컨트롤은 `accent-color`를 `--primary`로 맞춘다(`accent-primary`).

**타임라인**

- 눈금과 장면 표시: `--marker`(무채색). 로고의 눈금에 해당한다.
- 재생 헤드: 선 2px `bg-brand`, 시각 라벨은 `bg-brand-strong text-brand-foreground font-mono`.
- 재생 헤드가 지나간 구간을 칠한다면 `bg-brand-soft`.

**진행 표시:** 렌더·내보내기 진행 막대는 `bg-brand`, 트랙은 `bg-brand-soft` 또는 `bg-muted`. 스피너도 `text-brand`.

**사이드바 머리:** `mark.svg`(12–14px, `text-brand`) + "Motion Studio"(Pretendard 600).

- 상태를 색으로만 구분하지 않는다. 아이콘이나 글자를 같이 둔다.

## Motion Studio 0.7.0

- **첫 결과부터 보여 드려요**: 에이전트가 혼자 오래 다듬지 않고, 초안이 나오면 바로 보여 드려요. 진행 단계에 "초안이 나왔어요" 카드가 뜨면 **이대로 전달** 또는 **수정 요청**을 고르면 돼요. 의견을 한 번 주실 때마다 한 라운드예요. 품질 단계(빠르게·기본·런칭용)는 이제 에이전트가 혼자 다듬는 양과 점수 표시를 정해요.
- **고칠 곳 표시**: 플레이어 오른쪽 위 **고칠 곳 표시**를 누르고, 멈춘 장면에서 고칠 부분을 드래그로 감싸면 메시지에 첨부돼요. 에이전트가 그 순간 그 자리를 그대로 보기 때문에 설명을 길게 쓰지 않아도 돼요. 칩을 누르면 그 장면으로 가고, X를 누르면 표시가 지워져요. 여러 곳을 표시할 수 있어요.
- **느낌 손잡이**: 튀는 정도, 흔들림, 속도, 충격 같은 움직임의 느낌을 속성 패널의 슬라이더로 열어 둬요. 끄는 대로 미리보기가 바로 바뀌어서, 미세 조정은 에이전트를 기다리지 않아도 돼요.
- **검사는 꼭 필요한 것만**: 화면이 깨지는 문제만 에이전트가 고치고, 구도·멈춤 같은 나머지는 보여 드릴 때 메모로 알려 드려요. 3D 겹침 검사도 메모로만 알려 드려요.
- **응답이 멈출 때**: Claude 서버가 응답하지 않는 요청은 오래 기다리지 않고 다시 보내요(예전엔 최대 10~15분 기다렸어요). 그래도 실패하면 **다시 보내기** 버튼이 나와요. 하던 작업은 그대로 남아 있어요.

**받기**: Apple Silicon(M1 이후)은 `-arm64.dmg`, 인텔 맥은 나머지 하나.
처음 열 때 "확인되지 않은 개발자"가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.

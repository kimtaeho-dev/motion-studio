## Motion Studio 0.6.0

- **앱·웹에 넣을 애니메이션(Lottie)**: 새 필름 창에서 "어디에 쓰나요?"를 **앱·웹에 넣을 것**으로 고르면 개발자에게 넘길 Lottie 애니메이션을 만듭니다. 로더·성공 체크·아이콘처럼 작은 건 장면 표 승인 없이 바로 만들고, 웹·앱 플레이어에서도 똑같이 나오는지 검사한 뒤 넘깁니다. 내보내기에서 `.json`·`.lottie`로 받고, 속성 패널에서 바꾼 색은 파일에 그대로 들어갑니다.
- **Figma 링크로 만들기**: claude.ai 설정 → 커넥터에서 Figma를 연결해 두면, 채팅에 Figma 프레임 링크를 붙이기만 해도 그 화면의 글자·이미지·위치를 그대로 받아 움직입니다. 상상으로 다시 그리지 않아요. 편집 권한이 있는 파일이어야 하고, Figma 요금제에 따라 한 달에 읽을 수 있는 횟수가 정해져 있습니다.
- **첨부: 참고용 / 그대로 쓰기**: 첨부 파일 옆 표시를 눌러 쓰임을 고릅니다. 내 로고·아이콘·스크린샷은 **그대로 쓰기**로 주면 다시 그리지 않고 파일 그대로 넣습니다. SVG는 벡터 그대로 들어가 도형마다 따로 움직일 수 있어요.
- **더 빠르게**: Lottie 애니메이션이 만들기는 2배 이상, 고치기는 3배쯤 빨라졌습니다. 영상 필름은 검수할 때 화면 속 작은 글자가 실제로 읽히는지 하나씩 확인합니다.
- 내보내기 창이 필름에 맞는 형식을 먼저 골라 둡니다(Lottie 필름은 Lottie, 투명 배경 필름은 ProRes·WebM). 투명 배경 필름의 MP4는 체커보드 위에 나옵니다(MP4는 투명을 담지 못해요).
- 창이 좁을 때 플레이어 위 내보내기 버튼이 잘리던 문제, 한글 이름으로 만든 필름의 폴더 이름이 알아보기 어렵던 문제를 고쳤습니다.

**받기**: Apple Silicon(M1 이후)은 `-arm64.dmg`, 인텔 맥은 나머지 하나.
처음 열 때 "확인되지 않은 개발자"가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.

## Motion Studio 0.4.0

물리와 자동 검사가 들어간 판입니다. 떨어지고 부딪히고 쌓이는 장면을 만들 수 있고, 에이전트가 물체끼리 겹치거나 화면에서 잘리는 곳을 스스로 찾아 고칩니다.

- **물리**: 중력·마찰·반발·충돌을 계산합니다. 글자나 상자가 비트에 맞춰 정확히 착지하고, 앞 물체 위에 쌓을 수도 있습니다. 착지할 때 살짝 눌렸다 돌아오고, 바닥에 닿을수록 그림자가 진해집니다.
- **자동 검사**: 물체끼리 파고듦, 바닥 아래, 가림, 화면 잘림, 둥둥 뜨는 낙하, 구도(여백)를 에이전트가 숫자로 확인하고 고칩니다. 같은 일을 이미지를 덜 보고 해서 제작 비용이 줄었습니다(같은 주문 기준 약 30%).
- **편집이 멈추지 않음**: 물리가 들어간 필름에서 문구·색·장면 시각을 바꿔도 앱이 멈추지 않습니다. 계산은 뒤에서 하고 끝나면 바로 바뀝니다.
- **전달한 필름은 그대로**: 전달 단계의 필름은 그때의 엔진으로 고정돼, 앱을 업데이트해도 같은 결과로 다시 렌더됩니다. 다시 고치면 최신 엔진으로 풀립니다.
- **새 샘플 "Sample · Physics drop"**: 글자가 비트마다 떨어져 서고 구슬이 튀어 멈추는 6초 영상. 기존 작업공간에도 한 번 추가됩니다.
- 3D 모델(.glb)을 채팅에 끌어다 놓아 쓸 수 있습니다.

**받기**: Apple Silicon(M1 이후)은 `-arm64.dmg`, 인텔 맥은 나머지 하나.
처음 열 때 "확인되지 않은 개발자"가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.

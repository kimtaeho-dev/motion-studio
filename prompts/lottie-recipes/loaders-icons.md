# 레시피: 로더 · 아이콘 · 상태 피드백

로더, 스피너, 진행 루프, 배지, 아이콘, 성공·실패·경고, 빈 상태, 작은 상태 애니메이션. 공통 규칙은 `prompts/lottie.md`.

## 기본

- 투명 배경. 크기 `512x512`(들어갈 자리가 정해져 있으면 그 비율).
- 로더·스피너·진행은 이음새 없는 루프. 성공·실패·경고는 한 번 재생 후 마지막 포즈에서 멈춘다(마지막 포즈 = 앱에 남는 아이콘).
- 작은 크기(24~48px)에서도 알아보는 형태. 얇은 선·작은 디테일을 줄인다.
- 서로 무관한 부품 여러 개보다, 기본 도형 하나를 위상 오프셋으로 반복.
- 매력 동작은 하나만(깜빡임, 맥박, 그리기 중 하나) — 브랜드 톤에 맞을 때.

## 프리셋

| 이름 | 무엇 |
|---|---|
| `orbital-loader` | 점·마크가 돈다. 회전은 360°의 정수배, 선형 |
| `stroke-trace` | 아이콘 선이 그려지고 잠깐 멈춘 뒤 초기화/루프 |
| `pulse-badge` | 상태 기호 주변의 작은 스케일·불투명도 맥박 |
| `check-complete` | 원 착지 → 체크 트림 그리기 → 짧은 착지 (`films/sample-lottie/` 참고) |
| `error-shake` | X·경고 강조. 짧고 통제된 좌우(±6~10px, 2~3회, 18~24f). 정신없지 않게 |
| `warning-pulse` | 삼각형·배지 등장 + 절제된 주의 맥박 1~2회 |
| `scan-progress` | 선형·원형 진행 스윕 |
| `phase-dots` | 점 3~5개가 오프셋 타이밍으로, 이음새가 맞는 루프 |

## 타이밍과 이징 (60fps)

- 상태 피드백: 30~75f, 마지막 포즈에서 멈춤(10~20f면 충분).
- 로더: 60~120f 루프.
- 선형은 회전·진행 루프에만. 성공 착지는 `.00,.65,.51,.99`(settle-soft) 또는 짧은 ease-out. UI 성공 상태에 넘침을 쓰지 않는다(브랜드가 분명히 장난스러울 때만, 4% 이하).

## 만들기

- 선·체크·링·원형 로더는 트림 패스(`tm`, 그룹당 하나). 원형 로더 = `el` + `st`(`lc: 2`) + `tm`의 `s`/`e`/`o` 키프레임.
- 루프: 값이 프레임 `op`에서 처음 값으로 돌아오게 키를 `t = op`에. 위치·색·불투명도·속도까지.
- 반복 요소는 레이어/그룹마다 키프레임 시작을 몇 프레임씩 밀어 위상 오프셋. 리피터(`rp`) 사본은 개별로 다르게 움직일 수 없다.
- 대시 점선 로더는 WARN — 트림 하나로 행진 효과를 만든다.
- 슬롯: 포인트 컬러, 필요하면 잉크 색·선 굵기. 칠한 배경일 때만 `bg`.

## 흔한 실패

- 루프 이음새가 보인다(속도가 끊김).
- 반복 부품이 같은 박자로 움직여 기계적이다.
- 움직이는 동안 아이콘을 알아볼 수 없다.
- 오류·경고가 너무 장난스럽다.
- 선 끝·이음이 두 렌더러에서 다르다(`--parity`로 확인).

## 통과 조건

- 루프면 이음새가 안 보인다. 한 번 재생이면 마지막 포즈가 깨끗한 아이콘이다.
- 반복은 의도하지 않는 한 위상 오프셋.
- 실제 크기로 줄여도 알아본다.
- 타이밍이 쓸모 있고 조급하지 않다.
- 투명 에셋에 배경 픽셀이 없다.

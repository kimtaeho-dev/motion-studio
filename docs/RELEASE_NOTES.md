## Motion Studio 0.4.1

0.4.0을 고친 판입니다.

- **완성한 필름이 안 열리던 문제 수정**: 전달(완성) 단계로 넘긴 필름이 플레이어에서 열리지 않던 문제를 고쳤습니다. 0.4.0에서 이 증상 때문에 단계를 되돌려 둔 필름은 이제 다시 완성 처리해도 됩니다.
- **전체 길이 바꾸기**: 플레이어 아래 시간 표시의 전체 길이(예: `12.0s`)를 누르거나, 속성 패널의 '길이'에서 초를 바꾸면 됩니다. 장면 시각이 같은 비율로 늘거나 줄고, 비트 위에 있던 장면은 비트에 다시 붙습니다. 동작 하나하나의 속도는 그대로라 슬로모션이 되지 않습니다. ⌘Z로 되돌릴 수 있습니다.

**받기**: Apple Silicon(M1 이후)은 `-arm64.dmg`, 인텔 맥은 나머지 하나.
처음 열 때 "확인되지 않은 개발자"가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.

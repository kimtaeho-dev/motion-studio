# 크리틱 패스 — 자기 프레임을 보고 고치기

먼저 실행: `node tools/critique.mjs films/<이름> [포맷] [빠른동작시각]`

그다음 아래 프롬프트대로 한다.

---

`out/<이름>/<포맷>/critique/`의 contact.png, strip.png, phone.png, seam.png를 열어서 제대로 본다.
자랑스러운 작가가 아니라 깐깐한 모션 디렉터로 본다.

채점 전에 두 가지를 먼저 대조한다. 점수는 그다음이다.
1. **의도 대조**: `index.html` 맨 위의 장면 의도를 한 줄씩 contact.png·strip.png와 맞춰 본다. 적어 둔 대로 그 비트에 그렇게 보이는지. 어긋나면 "고칠 점"이다.
2. **글자 대조**: phone.png(360px)에서 화면에 나오는 **모든 글자**를 하나씩 소리 내 읽듯 적어 본다(기기 화면 속 작은 글자·금액·카드번호·영수증 줄 포함). 하나라도 못 읽으면 폰 가독성은 6점 이하이고, 그 글자를 키우거나 빼는 것이 가장 큰 문제 1번이다.

1~10점으로 채점:

| 항목 | 기준 |
|---|---|
| 훅 | 첫 2초 안에 눈을 잡는가 |
| 폰 가독성 | 360px 폭에서 글자가 읽히는가 |
| 모션 품질 | 스프링이 살아 있는가, 죽은 프레임이 없는가 |
| 다양성 | 2~4초마다 새로운 일이 일어나는가 |
| 구도 | 여백, 정렬, 화면 채움 |
| 브랜드 정확도 | 색, 서체, 실제 UI/데이터 |
| 리듬 | 장면 전환과 큰 동작이 비트 그리드에 맞는가 |

가장 큰 문제 3개를 타임스탬프와 함께 적는다. 특히 찾을 것:
- 교체 중 텍스트 겹침
- 이징 대신 미끄러지는 움직임
- 모서리 라벨, 프레임 테두리
- 그라데이션 위 가운데 정렬 샷
- 카메라 스케일로 흐려진 텍스트
- 아무 일도 없는 비트
- 루프 이음새의 끊김 (seam.png: 왼쪽 6장 = 끝, 오른쪽 6장 = 처음)
- 3D: 파고듦·바닥 아래·가림·잘림·무게감·비트 착지는 `--check3d` 판정으로 본다(통과면 그림을 열지 않는다). 눈으로 볼 것만: 기기 화면 속 글자가 안 읽힘, 재질이 너무 많아 산만함

고친다 → 바뀐 구간만 `--from/--to`로 다시 렌더 → 새 컨택트 시트와 점수를 보여준다.
모든 항목 8점 이상이 될 때까지 최소 3라운드. 매 라운드 `films/<이름>/review_log.md`에 남긴다.

```md
## 라운드 N — YYYY-MM-DD
대조: 의도 맞음/어긋남(비트) · 글자 못 읽은 것: 없음 / "···· 4211"(3.0s) …
점수: 훅 7 · 가독성 6 · 모션 8 · 다양성 8 · 구도 7 · 브랜드 8 · 리듬 7
문제: 1) 4.2s 탭 라벨 겹침 2) … 3) …
수정: …
```

# 레시피: 시각 효과

광택 스윕, 글로우 대체, 그라데이션 채움, 빛 지나감, 버스트, 반짝임, 앰비언트 필드. 보통 **보조** 레시피다. 효과 자체가 결과물일 때만 주. 공통 규칙은 `prompts/lottie.md`.

## 기본

- 효과를 빼도 기본 구도가 읽혀야 한다. 효과는 약한 위계·여백·구도를 구하지 못한다 — 기본 디자인을 먼저 고친다.
- 효과마다 일이 있다: 리빌, 강조, 전환, 상태 피드백, 재질.
- 레이어 이펙트(`ef`)는 BLOCK, 블렌드 모드는 WARN. 블러·블룸·글래스·크롬·디더·진짜 3D·디스플레이스먼트는 Lottie로 같게 안 나온다 → 벡터 도형·`gf`·불투명도 층으로 흉내.
- CLAUDE.md 금지: UI 크롬의 글로우·그라데이션, 흔한 파티클 폭발.
- 로고·아이콘·오버레이와 같이 쓰면 투명 유지.

## 대체 표

| 원하는 것 | Lottie에서 |
|---|---|
| 드롭 섀도우 | 오프셋 복제 레이어 + 어두운 단색 + 낮은 불투명도 |
| 글로우·후광 | 뒤에 방사형 `gf`(중심 색 → 같은 색 알파 0) |
| 광택·글래스 스윕 | 대상 위를 지나가는 기울어진 얇은 `rc` + 선형 `gf`, 대상 모양 밖으로 나가면 안 되면 알파 매트(WARN — `--parity` 확인) 또는 단색 배경일 때 덮개 |
| 틴트 | `fl` 색 직접 키프레임 |
| 블러 | 빼거나 미리 렌더한 이미지 에셋 |
| 모션 블러 | 오프셋 복제 레이어 2~3개, 낮은 불투명도 |

## 프리셋

`glass-sweep`(기울어진 반투명 지나감) · `metal-sheen`(좁은 하이라이트 빠르게) · `soft-glow`(주인공 뒤 낮은 진폭 후광 맥박) · `gradient-fill`(도형·단어를 지나는 색 채움) · `bubble-burst`(성공·리빌 주변 원이 퍼지며 사라짐) · `spark-accent`(마지막 착지 주변 작은 하이라이트) · `ambient-field`(앵커 하나에서 나온 조용한 2톤 필드 루프) · `phase-primitive`(기본 도형 하나 반복, 위상 오프셋, 이음새 없는 루프).

## 목적과 짝 짓기

- 아무 글로우 → 주인공·활성 상태·마지막 착지에 묶인 초점 후광, 또는 없음.
- 흩어진 원 → 행동 상태 피드백, 버스트 원점에서 나온 입자, 또는 삭제.
- 흔한 스윕 → 특정 표면(로고 가장자리, 글자 면, 카드, 제품 화면)을 지나는 재질 패스.
- 탁한 그라데이션 → 의미 있는 채움(진행, 선택, 전송, 리빌, 브랜드 색 전환).
- "프리미엄" = 절제, 선명한 리빌, 일관된 재질, 깨끗한 마지막 프레임. 글로우를 더 쌓는 게 아니다.
- 필드는 흔한 입자 흩뿌리기보다 주인공에서 나온 것(물결, 등고선, 궤도 점).

## 타이밍과 이징 (60fps)

- 스윕: 30~75f, 주 리빌보다 빠르게, 선형 또는 거의 선형.
- 글로우 맥박: 45~90f, 낮은 진폭.
- 버스트: 20~45f, 확장은 ease-out(`.20,.75,.34,.94`) + 불투명도 감소.
- 앰비언트가 아니면 효과를 오래 남기지 않는다.

## 만들기

- 효과 레이어는 따로, 이름 붙여.
- 입자·궤도·노이즈는 시드를 정해 키프레임으로 굽는다(표현식 BLOCK). 입자 수를 제한한다(150KB 예산).
- 앰비언트: 앵커 하나, 필드 하나, 바탕 하나, 움직임 원형 하나.
- 글자 위 효과는 가독성을 확인한 뒤에만.

## 흔한 실패

- 효과가 메시지를 덮는다. 글로우·스윕이 캔버스 가장자리에서 잘린다.
- 그라데이션이 탁해진다. 버스트가 행동 비트에 묶이지 않아 무작위다.
- 프리미엄 처리가 글로우·글래스·그라데이션 더미가 된다.
- Skottie에서만 되는 효과를 약속한다.

## 통과 조건

- 효과의 목적이 마지막 프레임에서도 보인다. 효과를 빼도 구도가 강하다.
- 효과가 지나간 뒤 마지막 프레임이 깨끗하다. 의도하지 않은 배경 픽셀이 없다.
- `--parity` 통과 — 두 렌더러에서 강도·잘림이 같다.

# 레시피: 로고 애니메이션

브랜드 마크, 워드마크, 로고 리빌, 인트로·아웃트로 마크, 앱 스플래시. 공통 규칙은 `prompts/lottie.md`. 원본이 SVG면 `svg-animation.md`도 읽는다.

## 기본

- 브랜드 모양·색·간격·최종 락업을 지킨다(재디자인 요청이 없으면). 디자이너가 **그대로 쓰기**로 준 로고는 패스를 옮기고, 눈대중으로 다시 그리지 않는다.
- 투명 배경.
- 생성 → 착지 → 멈춤. 멈춘 락업에서 브랜드가 각인된다.
- 브랜드 제약은 원본으로 알 수 없을 때만 묻는다.

## 프리셋

| 이름 | 무엇 |
|---|---|
| `mark-draw` | 선·윤곽 로고를 트림으로 그린다(채움은 그리기가 끝날 무렵) |
| `assemble-settle` | 조각이 가까운 오프셋에서 들어와 마크로 맞춰진다 |
| `premium-reveal` | 스케일 착지(96→100%) + 짧은 불투명도. 전부 페이드인으로 끝내지 않는다 |
| `accent-sweep` | 브랜드 포인트가 마크를 지나가고 사라진다 |
| `wordmark-cascade` | 글자·단어 묶음이 절제된 엇갈림으로 |
| `splash-pop` | 짧은 앱 스플래시 리빌 + 짧은 멈춤 |
| `shape-vocabulary-build` | 브랜드 도형이 먼저 조립되고 워드마크가 보상으로 착지 |

## 타이밍과 이징 (60fps)

- 단순 마크: 45~75f. 마크 + 워드마크: 75~120f.
- 마크 착지 `.00,.65,.51,.99`(heavy에 해당), 조각 이동 `.65,0,.35,1`. 넘침은 브랜드가 분명히 장난스러울 때만.
- 마지막 10~20f는 락업이 완전히 정지.

## 만들기

- 마크, 워드마크, 액센트를 레이어(또는 그룹)로 나누고 `nm`을 붙인다.
- 최종 포즈는 원본 로고와 정확히 같다(비율·간격·회전·정렬). 움직이는 동안 워드마크 자간이 흔들리지 않게 글자 그룹의 최종 위치를 원본 좌표에 둔다.
- 특징적인 모듈·획·도형이 있으면 그것을 먼저 움직이고 워드마크는 나중에. 답을 너무 일찍 다 보여주지 않는다.
- 찌그러짐·바운스·회전·블러류로 브랜드 형태를 왜곡하지 않는다(요청이 없으면).
- 워드마크가 SVG에 글자(`<text>`)로만 있으면 아웃라인 SVG를 받거나 서체가 Pretendard/Geist일 때 `lottie.mjs text`로.
- 칠한 배경을 요청받았을 때만 `bg` 슬롯. 로고 색 슬롯은 디자이너가 바꿀 이유가 있을 때만(다크 모드 변형 등).

## 흔한 실패

- 마지막 프레임이 원본 락업과 다르다.
- 워드마크 자간이 움직이는 동안이나 뒤에 흐트러진다.
- 장식 효과가 브랜드 인식을 덮는다.
- 워드마크가 빌드가 끝나기 전에 나온다.
- 투명 에셋에 배경 픽셀이 섞였다.

## 통과 조건

- 마지막 프레임이 원본에 충실한 락업이다(원본 SVG와 같은 크기로 스틸 비교).
- 락업이 읽힐 만큼 멈춘다.
- 투명 에셋에 의도하지 않은 배경이 없다.
- 브랜드에 맞는 움직임이고 흔하지 않다.
- 교차·구멍·선이 `--parity`에서 두 렌더러 모두 맞다.

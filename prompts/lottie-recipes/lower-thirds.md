# 레시피: 이름표 · 캡션 띠 · 오버레이 라벨

이름표(로워서드), 화자 표시, 캡션 띠, 소셜 핸들, 라벨, 투명 오버레이 글자. 앱 안의 라벨·배너 오버레이도 여기. 공통 규칙은 `prompts/lottie.md`.

## 기본

- 투명 배경. 안전 여백 안, 캔버스 가장자리를 피한다.
- 빨리 읽히는 것이 최우선.
- 이름·직함·문구가 없으면 묻는다. 문구는 `lottie.mjs text` 아웃라인이라 속성 패널에서 바뀌지 않는다 — 여러 사람용이면 디자이너에게 알리고, 문구마다 다시 만든다.

## 프리셋

| 이름 | 무엇 |
|---|---|
| `clean-slide` | 띠·글자가 밀려 들어와 부드럽게 착지 |
| `broadcast-snap` | 빠른 블록, 선명한 엇갈림, 확신 있는 퇴장 |
| `minimal-line` | 얇은 포인트 선이 그려지고 글자가 따라옴 |
| `pill-reveal` | 둥근 컨테이너가 글자 주위로 열림 |
| `social-tag` | 아이콘·핸들이 짧게 등장하고 멈춤 |
| `caption-strap` | 절제된 띠, 강한 가독성 |

## 타이밍과 이징 (60fps)

- 등장: 45~90f. 퇴장(요청 시): 30~60f, `1.00,.02,.54,.42`.
- 띠는 빠른 ease-out(`.20,.75,.34,.94`), 글자는 더 부드럽게(`.00,.65,.51,.99`), 띠보다 4~8f 늦게.
- 멈춘 상태가 안정적이어야 편집 타임라인에서 재사용된다. 등장·멈춤·퇴장 구간을 프레임으로 적어 전달한다.

## 만들기

- 요소를 한 널 부모 아래 묶어 위치를 한 번에 옮길 수 있게.
- 컨테이너 리빌은 마스크(WARN) 대신 `rc`의 `s`(폭) 키프레임 — 모서리 반경이 그대로다. `pill-reveal`도 같은 방법.
- 글자가 띠 밖으로 나가 보이면 안 되는 리빌은, 글자를 띠 안쪽에서 위치 이동 + 불투명도로(클리핑 없이 읽히게).
- 슬롯: 포인트 색, 띠 색.

## 흔한 실패

- 실제 영상·화면 위에서 글자가 너무 작다.
- 오버레이가 화면을 너무 많이 차지한다.
- 등장 움직임이 화자·내용을 방해한다.
- 배경이 실수로 불투명하다.

## 통과 조건

- 다양한 배경 위에서 읽힌다(밝은·어두운 바탕 스틸 둘 다 상상해 대비 확인).
- 요청이 없으면 투명이다.
- 등장·퇴장이 화면을 과하게 가리지 않는다.
- 멈춘 상태가 균형 잡혀 있다.

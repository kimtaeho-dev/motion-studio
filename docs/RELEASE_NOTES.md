## Motion Studio 0.6.2

> ⚠️ **업데이트 후 처음 열 때 한 번 다시 로그인해야 해요.** 앱이 이제 자기만의 Claude 로그인을 써요. 필름과 대화 기록은 그대로 이어집니다.

- **질문은 선택지로**: 새 필름을 요청하면 에이전트가 묻는 것들이 채팅에 선택지 카드로 떠요. 고르기만 하면 되고, 원하는 게 없으면 "직접 입력"에 쓰면 돼요. 추천하는 선택지에는 "추천"이 붙어요.
- **설정**: 사이드바 아래 ⚙ 설정(또는 ⌘,)에서 쓰고 있는 Claude 계정과 요금제를 보고, 다른 계정으로 바꿀 수 있어요. 앱 안에서 계정을 바꿔도 터미널이나 다른 앱의 Claude Code 계정은 그대로예요. 작업 폴더도 Finder에서 바로 열 수 있어요.
- **스타일이 더 자유롭게**: 크레용·손그림 같은 화풍을 요청하면 그 화풍에 맞는 방법으로 그려요. UI 모션의 기본 규칙에 끼워 맞추지 않아요.
- **더 꼼꼼한 검사**: 화면이 멈춘 구간, 한쪽으로 쏠린 구도, 빈 화면, 번쩍임, 루프 이음새를 에이전트가 눈대중이 아니라 자동 검사로 잡고 고쳐요.
- 채팅에 파일을 첨부했을 때 칩이 입력창 위 선에 붙어 보이던 문제를 고쳤어요.
- (0.6.1) 처음 설치했을 때 직접 만들지 않은 샘플 필름이 목록에 보이던 문제 수정.

**받기**: Apple Silicon(M1 이후)은 `-arm64.dmg`, 인텔 맥은 나머지 하나.
처음 열 때 "확인되지 않은 개발자"가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.

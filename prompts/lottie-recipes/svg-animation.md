# 레시피: SVG 애니메이션

"이 SVG 움직여줘", SVG → Lottie, 벡터 일러스트 리빌. 로고·아이콘·UI·다이어그램이 주 결과물이면 그 레시피가 주, 이 문서가 보조. 변환 규칙의 요약은 `prompts/lottie.md`의 [SVG 에셋](../lottie.md#svg-에셋).

## 기본

- 디자이너가 **그대로 쓰기**로 준 SVG(`refs/`)는 패스를 옮긴다. 눈대중으로 다시 그리지 않는다.
- 투명 배경(화면 전체 일러스트이거나 요청이 있을 때만 배경).
- 원본 구도와 viewBox를 지킨다. 마지막 정지 프레임 = 원본.
- 의미 있는 구조(그룹, 패스, 선, 액센트, 시선 흐름)를 움직인다.

## 받기 (막는 게 싸다)

1. viewBox, width/height, 원점, 그룹, transform, 마스크·clipPath, 그라데이션, `<style>`·class, `<text>`, filter를 먼저 확인한다.
2. 문제가 될 것을 디자이너에게 한 번에 알린다: `<text>`(아웃라인 SVG 요청), filter·blur·blend(빠진다), 복잡한 clipPath·mask(대체 방법), 선 확장이 필요한 경우.
3. 레이어 이름은 의미 있게(마크, 잎, 화살표…).

## 옮기기

- 패스 → `sh`: 절대좌표로 풀고 베지어 제어점은 정점 기준 상대좌표로 `i`·`o`. 2차 곡선은 3차로(제어점 = 끝점 + 2/3 × (q − 끝점)). 닫힌 패스는 `c: true`.
- 중첩 transform은 가능하면 정점에 미리 곱한다. 애니메이션 단위로 쓸 그룹만 남기고 나머지는 평탄화.
- 칠 규칙: `evenodd` → `fl.r: 2`, `nonzero` → `1`. 구멍은 같은 그룹 안 여러 `sh` + 한 `fl`. 머지 패스 금지(BLOCK). 겹친 하위 패스로 면을 지우는 모양은 단순한 도형 스택으로 다시 나눈다.
- 스타일: class·상속·CSS 변수를 `fl`/`st` 값으로 풀어 쓴다. 단순 선형·방사 그라데이션만 `gf`로. gradientTransform이 있으면 시작·끝점을 계산해 넣고 스틸로 비교.
- 선: 트림 그리기가 애니메이션 자체면 `st`로 두고 `lc`·`lj`·`ml`을 원본대로. 아니면 칠로 확장된 SVG가 안전하다.
- 깔끔한 아이콘은 정수 좌표에 맞춰 흐린 가장자리를 피한다.
- 원시 도형(`rect`·`circle`·`ellipse`)은 `rc`·`el`로 옮기면 크기 키프레임 리빌을 쓰기 쉽다.

## 프리셋

| 이름 | 무엇 |
|---|---|
| `path-draw` | 선이 트림으로 그려진 뒤 착지·채움 |
| `layer-unfold` | 그룹이 깊이·읽는 순서로 드러남 |
| `fill-sweep` | 면에 방향 있는 색·불투명도 리빌 |
| `illustration-drift` | 리빌 뒤 아주 작은 그룹 패럴랙스(루프면 이음새 맞춤) |
| `morph-lite` | 작은 모양·위치 변화. 정점 구조가 같을 때만 |

## 타이밍과 이징 (60fps)

- 단순 SVG·아이콘: 45~90f. 복잡한 일러스트: 90~180f.
- 트림 속도는 패스의 보이는 길이에 비례(짧은 패스는 짧게). 조립은 `.00,.65,.51,.99`.

## 흔한 실패

- 마지막 프레임이 원본과 다르다.
- 숨은 CSS 스타일이 변환 후 사라졌다.
- 칠 규칙·마스크 때문에 구멍·교차가 깨졌다.
- 임의 패스 조각이 읽히는 의도 없이 움직인다.

## 통과 조건

- 정지 프레임이 원본 SVG와 같은 크기에서 시각적으로 같다(창작 변형 요청이 없으면).
- 구멍·잘림·그라데이션·교차가 `--parity`에서 두 렌더러 모두 맞다.
- 읽는 순서나 리빌 논리가 분명하다.
- 배경 정책이 의도한 대로다.

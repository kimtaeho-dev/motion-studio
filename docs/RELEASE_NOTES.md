## Motion Studio 0.3.0

3D가 들어간 판입니다. 이제 기기 목업, 입체 글자, 제품 모델로 영상을 만들 수 있습니다.

- **기기 목업**: 폰·노트북 안에서 화면 UI가 실제로 움직이고, 기기째 돌고 떠오르고 카메라가 다가갑니다.
- **입체 글자**: 한글은 Pretendard, 영문은 Geist로 두께와 재질이 있는 글자를 만듭니다.
- **재질과 조명**: 플라스틱·무광·클레이·금속·크롬·유리·진주빛 재질, 스튜디오·부드러운·극적인 조명. 투명 배경으로 내보내도 그림자가 남습니다.
- **제품 모델**: 채팅창에 .glb 파일을 끌어다 놓으면 그 모델로 영상을 만듭니다. 모델 안 애니메이션도 씁니다.
- **새 샘플 "Sample · 3D product"**: 폰 속 결제 화면 + 입체 글자 + 도형이 움직이는 8초 루프. 기존 작업공간에도 한 번 추가됩니다(지우면 다시 생기지 않습니다).
- 3D는 맥의 GPU로 그립니다. 같은 맥에서는 몇 번을 렌더해도 같은 결과가 나옵니다.

**받기**: Apple Silicon(M1 이후)은 `-arm64.dmg`, 인텔 맥은 나머지 하나.
처음 열 때 "확인되지 않은 개발자"가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.

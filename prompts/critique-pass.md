# 크리틱 패스 — 자기 프레임을 보고 고치기

먼저 실행: `node tools/critique.mjs films/<이름> [포맷] [빠른동작시각]`

그다음 아래 프롬프트대로 한다.

---

`out/<이름>/<포맷>/critique/`의 contact.png, strip.png, phone.png, seam.png를 열어서 제대로 본다.
자랑스러운 작가가 아니라 깐깐한 모션 디렉터로 본다.

1~10점으로 채점:

| 항목 | 기준 |
|---|---|
| 훅 | 첫 2초 안에 눈을 잡는가 |
| 폰 가독성 | 360px 폭에서 글자가 읽히는가 |
| 모션 품질 | 스프링이 살아 있는가, 죽은 프레임이 없는가 |
| 다양성 | 2~4초마다 새로운 일이 일어나는가 |
| 구도 | 여백, 정렬, 화면 채움 |
| 브랜드 정확도 | 색, 서체, 실제 UI/데이터 |
| 리듬 | 장면 전환과 큰 동작이 비트 그리드에 맞는가 |

가장 큰 문제 3개를 타임스탬프와 함께 적는다. 특히 찾을 것:
- 교체 중 텍스트 겹침
- 이징 대신 미끄러지는 움직임
- 모서리 라벨, 프레임 테두리
- 그라데이션 위 가운데 정렬 샷
- 카메라 스케일로 흐려진 텍스트
- 아무 일도 없는 비트
- 루프 이음새의 끊김 (seam.png: 왼쪽 6장 = 끝, 오른쪽 6장 = 처음)
- 3D: 기기 화면 속 글자가 안 읽힘, 물체가 화면 끝에서 잘림(9x16에서 특히), 그림자가 중간에 잘림, 물체끼리 파고듦, 재질이 너무 많아 산만함 — `--check3d` 보고서로 확인
- 무게감(모션 품질 점수에 반영): 떨어지는 물체가 가속하지 않고 일정하게 내려옴, 바닥 위에서 서서히 멈춤(둥둥 뜸), 닿는 순간 그림자가 진해지지 않음, 튐이 줄지 않음, 착지가 비트에서 벗어남 — `check3d/motion.png`로 확인

고친다 → 바뀐 구간만 `--from/--to`로 다시 렌더 → 새 컨택트 시트와 점수를 보여준다.
모든 항목 8점 이상이 될 때까지 최소 3라운드. 매 라운드 `films/<이름>/review_log.md`에 남긴다.

```md
## 라운드 N — YYYY-MM-DD
점수: 훅 7 · 가독성 6 · 모션 8 · 다양성 8 · 구도 7 · 브랜드 8 · 리듬 7
문제: 1) 4.2s 탭 라벨 겹침 2) … 3) …
수정: …
```

# 3D · 물리 · 3D 검사 — 규칙과 API

3D(기기 목업·제품 모델·입체 글자·재질 도형)나 물리를 쓰는 필름은 **숏리스트 승인 뒤 구현에 들어갈 때** 이 문서를 읽는다.
2D API는 `prompts/api.md`. `lib/*.js` 소스는 통째로 읽지 않는다(여기 없는 걸 찾을 때만 `grep`으로 그 부분).
더 긴 예시: `films/sample-3d/`(배치·카메라·기기 화면), `films/sample-physics/`(물리) — 막힐 때만 본다.

## 규칙

- 기기 목업(폰·노트북), 제품 모델(.glb), 입체 글자, 재질이 있는 도형이 필요하면 3D를 쓴다. 평면 UI 모핑만이면 2D로 충분하다.
- `lib/stage3d.js`만 쓴다: `world`(장면·카메라·조명 프리셋 studio/soft/dramatic), `phone`·`laptop`(화면 = `screen()` 2D 캔버스), `text3d`·`fonts3d`, `material`(plastic·matte·clay·metal·chrome·glass·pearl), `model`, `set`, `physics`. 쓰는 법은 파일 맨 위 주석과 `films/sample-3d/`(배치·카메라), `films/sample-physics/`(물리).
- 3D 장면을 three.js로 직접 새로 짜지 않는다. 프리셋에 없는 모양은 `THREE`의 기본 지오메트리에 `material()`을 입혀 만든다.
- 순수 함수 규칙은 그대로다. `draw` 안에서 모든 물체의 위치·회전·스케일과 카메라를 t로부터 다시 정한다(`set`, `W.fit`). 이전 프레임 값에 더하지 않는다. 움직임은 2D와 같이 `track`·`loopTrack` 스프링.
- `world()`·재질·기기·글자는 `Stage.film` 함수 안에서 만든다. 폰트(`await fonts3d()`)와 모델(`await model('refs/x.glb')`)만 그 밖에서 한 번 불러온다.
- 기기 화면 속 UI는 `screen().draw((g, w, h) => ...)`에서 2D로 그린다. 2D 규칙(swapAlpha, 스프링)이 그대로 적용된다. 화면 글자는 폰이 가장 작게 보이는 프레임에서도 읽혀야 한다.
- 포맷마다 배치 표를 따로 두고(`S.portrait`/`S.landscape`, 물리처럼 draw 전에 필요하면 `film.portrait`/`film.landscape`), `W.fit(S, { width, height })`로 그 영역이 화면에 다 들어오게 한다. 크롭하지 않는다.
- 물체는 이름을 붙여 넣는다: `W.add({ 폰: ph, 캡슐: cap })`. 검사 보고서와 그림에 그 이름이 나온다.
- 바닥에 놓이는 물체에는 접지 그림자가 자동으로 붙는다(닿을수록 작고 진하게). 물체가 떠 있으면 일부러 띄운 것인지 확인한다.
- 3D 모델은 디자이너가 준 .glb(`refs/`)만 쓴다. 인터넷에서 받지 않는다.
- 룩: 조명 프리셋 하나, 재질은 2~3종. 블룸·글로우·렌즈 플레어 같은 후처리는 쓰지 않는다. 그림자가 화면 밖에서 잘리면 `world({ shadowArea })`를 키운다.

### 물리 (무게·충돌)

- 고르는 기준: 물체끼리 부딪히거나 쌓이거나 굴러가면 `physics()`(미리 굽기). 하나가 떨어지거나 미끄러지기만 하면 `M.drop`·`M.slide`·`M.arc` 곡선(2D에도 쓴다). UI 전환·카메라·기기 회전은 지금처럼 스프링.
- 물리는 `Stage.film` 함수 안에서 `sim.bake(film.dur)`로 0초부터 끝까지 미리 계산하고, `draw` 맨 앞에서 `sim.apply(t)`로 꺼내 쓴다. 그래서 여전히 t의 순수 함수다. `await physicsReady()`는 밖에서 한 번.
- 키프레임으로 움직이는 물체(폰 회전 등)도 `sim.kinematic(obj, t => ({ pos, rot }))`로 넣어야 다른 물체가 거기 부딪힌다. 넣지 않으면 뚫고 지나간다.
- 착지는 비트에 맞춘다: `sim.body(obj, { pos: 'above', land: { at: film.T.hit, pos: [x, z] } })`. `pos: 'above'`는 착지 자리 바로 위 화면 밖에서 기다리게 하고, `at`(놓는 시각)을 빼면 "그냥 놓아서 그 비트에 닿는" 시각을 계산한다. 이게 기본이다. 억지로 위로 던지는 설정이면 보고서의 `물리 설정` 줄이 알려 준다.
- 느낌은 `feel` 프리셋(snappy 기본 · heavy · floaty · real)으로 고르고, 중력 숫자를 직접 넣지 않는다(단위가 자동 환산된다). 세울 물체(밑이 둥근 글자 등)는 `upright: true`.
- 기다리는 자리를 손으로 정하면 너무 높아 세게 떨어지거나(튀어 나감), 서로 겹쳐 놓는 순간 튕긴다. `pos: 'above'`를 쓰면 둘 다 코드가 막는다.
- 그릇에 담거나 쌓을 때는 착지 자리를 `pile(objs, { radius, radiusTop, on, size, height })`로 받는다. 같은 자리에 여러 개를 떨어뜨리면 서로 끼어 끝없이 부딪힌다(보고서 `물리 설정`·`끼임` 줄). pile이 돌려주는 층 수로 담길 높이를 먼저 확인하고, 그릇보다 높으면 개수·크기를 줄인다.
- 쌓을 물체(상자, 코인 탑)는 `bounce: 0.02, friction: 0.95, upright: true`로 놓는다. 기본값으로 떨어뜨리면 위 물체가 아래 물체를 치고 흩어진다.
- `pos: 'above'`로 기다리는 물체는 엔진이 놓기 직전까지 숨긴다(그림자가 미리 비치지 않게). 따로 숨길 필요 없다.
- 그릇이 "가득 차 보이게" 하려면 실제로 채우지 말고 **가짜 바닥**을 쓴다: 그릇 안 높은 곳에 안 보이는 원판(`visible = false`, 그릇과 같은 키프레임 물체에 붙인다)을 두고 그 위에 pile로 쌓는다. 적은 개수로 넘칠 듯 보인다.
- 물리로 쌓인 장면은 처음으로 저절로 돌아가지 않는다. 루프가 필요하면 화면 밖으로 치우는 연출을 넣거나, 마지막 구간만 스프링으로 되돌린다. 아니면 루프가 아닌 필름으로 만든다.

### 3D 검사 (코드가 판정, AI는 실패했을 때만)

- 검사는 코드가 한다: `node tools/render.mjs films/<이름> --check3d`. 첫 줄이 판정이다. **`판정: 통과`면 그림을 열지 않고 다음으로 간다.**
- 실패하면 각 문제 아래 `→` 줄에 고치는 법이 숫자로 나온다(옮길 벡터, 카메라 배율 등. 다른 물체와 안 겹치는 자리를 코드가 골라 둔 것). 그대로 적용하고 한 번 더 검사한다. `views.png`·`motion.png`는 `→`가 "빈자리가 없다"이거나 같은 문제가 두 번 남을 때만 연다.
- 고치는 라운드는 단계마다 2번까지. 그래도 남으면 의도한 것인지 판단해서 `W.allow({ 이름: ['occluded'] })`(시간 구간만: `{ 이름: { occluded: [3.4, 3.7] } }`)로 표시하거나, 남은 문제를 디자이너에게 한 줄로 알리고 넘어간다.
- 작업 중에는 주 포맷 하나만 검사한다. 모든 포맷 검사는 전달 직전에 한 번.
- 무게감도 코드가 본다: 바닥에 닿기 직전 느려지는 낙하(둥둥 내려앉음)는 `무게감`으로, 물리 착지가 비트에서 벗어나면 `비트` 줄로 나온다.
- **구도도 숫자로 맞춘다.** 보고서의 `구도` 줄이 비트마다 내용(3D + 화면 글자)의 여백(위/아래/왼/오 %)을 주고, 꽉 차거나(<3%) 비거나(>30%) 작은 구간에 카메라 숫자(margin 배수, at 이동 — 화면 글자를 피한 빈 영역에 여백 8%로)를 제안한다. 화면 글자와 3D가 겹치면 알려 준다. 숫자대로 고치고 한 번 더 검사한다(카메라 원근 때문에 한 번에 다 맞지 않을 수 있다). 제안은 연출을 모른다: 카피가 나오기 전 빈 화면처럼 의도한 여백이면 따르지 않는다. 컨택트 시트로 구도를 맞추며 반복하지 않는다 — 컨택트 시트는 숫자로 맞춘 뒤 한 번 본다.
- 미리 막는 게 싸다: 줄 세우기는 `row()`(폭대로 간격), 떨어뜨리기는 `pos: 'above'` + `land`(화면 바로 위에서 비트에 착지), 카메라는 Stage.film 안에서 `W.fit(film, ...)`로 먼저 잡는다. 좌표를 손으로 계산할수록 검사 라운드가 늘어난다.

## 뼈대

```html
<script src="../../lib/motion.js"></script>
<script src="../../lib/stage.js"></script>
<script type="importmap">
{ "imports": { "three": "../../lib/three/three.module.js", "three/addons/": "../../lib/three/addons/" } }
</script>
<script type="module">
import { THREE, world, phone, laptop, screen, text3d, fonts3d, material, model, set, deg, row, pile, physics, physicsReady, G } from '../../lib/stage3d.js';
const { track, loopTrack, sp, clamp, lerp, swapAlpha } = M;
await fonts3d();                 // 입체 글자를 쓰면
await physicsReady();            // 물리를 쓰면
// const can = await model('refs/can.glb', { size: 1.2 });   // 모델을 쓰면 (한 번만)

Stage.film((film) => {
  const { P, T, dur: DUR } = film;
  const W = world({ light: 'studio', ground: -1.6 });
  const ui = screen();                                   // 폰 화면 = 2D 캔버스 780×1688
  const ph = phone({ screen: ui });
  const word = text3d(P.word, { size: 0.6, mat: material('plastic', P.accent) });
  W.add({ 폰: ph, 글자: word });                          // 이름 = 검사 보고서에 나오는 이름

  const LAYOUT = { square: { frame: { width: 5, height: 3.6, at: [0, 0, 0] } }, portrait: { ... }, landscape: { ... } };
  const L = LAYOUT[film.portrait ? 'portrait' : film.landscape ? 'landscape' : 'square'];
  W.fit(film, L.frame);                                  // 물리 pos: 'above'를 쓰면 bake 전에 카메라를 잡아 둔다

  const sim = physics(W, { feel: 'snappy' });            // 물리를 쓰면
  sim.kinematic(ph, (t) => ({ pos: [-1, 0, 0], rot: [0, track(t, [[0, 0.3], [T.turn, -0.3]], ...sp('camera')), 0] }));
  sim.body(word, { pos: 'above', land: { at: T.hit, pos: [1, 0.3] }, upright: true });
  sim.bake(DUR);

  return {
    draw(g, t, S) {
      if (!S.transparent) { g.fillStyle = P.bg; g.fillRect(0, 0, S.W, S.H); }
      ui.draw((sg, w, h) => { /* 2D로 화면 UI를 t에 따라 */ });
      sim.apply(t);                                      // 물리 자세 (키프레임 물체 포함)
      // 물리가 아닌 물체: set(obj, { pos, rot, scale }) — 매 프레임 t로
      W.fit(S, { ...L.frame, margin: lerp(1.1, 1.0, track(t, [[0, 0], [T.turn, 1]], ...sp('camera'))) });
      W.render(g, S);
      // 화면 위 2D 글자(카피)는 W.render 뒤에 g로 그린다
    },
  };
});
</script>
```

## API — lib/stage3d.js

| 함수 | 설명 |
|---|---|
| `world({ light='studio', shadow=true, ground=-1.6, shadowArea=6, fov=30, contactShadows=true })` | 장면. light: `studio`(기본) · `soft`(밝은 프로덕트) · `dramatic`(어두운 환경 + 림). ground = 바닥(그림자 받이) y, null이면 바닥 없음 |
| `W.add(obj, ...)` · `W.add({ 이름: obj })` | 장면에 넣기. 이름을 붙이면 검사 보고서에 그 이름 |
| `W.fit(S 또는 film, { width, height, at=[0,0,0], dir=[0,0.12,1], margin=1.08, fov })` | width×height(월드 단위) 영역이 포맷과 상관없이 다 들어오게 카메라를 놓는다. dir = at에서 카메라 쪽 방향 |
| `W.look(from, at, fov?)` | 카메라 직접 놓기 |
| `W.render(g, S)` | 그려서 2D 캔버스에 얹는다. 배경은 그 전에 2D로 |
| `W.allow({ 이름: ['occluded', ...] })` | 의도한 가림·잘림 등 — 검사가 실패로 안 센다. `{ 이름: { occluded: [3.4, 3.7] } }`(구간만), `'코인*'`(이름 묶음), `{ 구도: [0, 1.5] }`(구도 지적 빼기) |
| `W.skyAt(x, z, below)` | (x,z) 위에서 화면 위로 막 벗어나는 높이 |
| `W.camera` · `W.key`(키 라이트) · `W.scene` · `W.floor` · `W.ground` | three.js 객체 직접 조정이 필요할 때 |
| `material(kind='plastic', color, opts)` | `plastic` · `matte` · `clay` · `metal` · `chrome` · `glass` · `pearl`. opts는 MeshPhysicalMaterial 값 덮어쓰기 |
| `screen({ width=780, height=1688 })` | 기기 화면 캔버스. `ui.draw((g, w, h) => ...)` 매 프레임 t로 |
| `phone({ screen, color='graphite' })` | 높이 3.04 · 폭 1.48 · 두께 0.15, 가운데가 원점. color: `graphite` `silver` `white` `black` 또는 hex |
| `laptop({ screen, color='silver' })` | 바닥 3.0×2.0, 바닥면이 y=0. 화면 16:10 → `screen({ width: 1440, height: 900 })`. `lt.open(p)`: 0 닫힘 → 1 열림(105°), 매 프레임 |
| `await fonts3d(...specs)` | 입체 글자 폰트. 기본 `'Geist 700'`, `'Pretendard 700'`. 600도 있음 |
| `text3d(str, { size=0.6, depth=size*0.35, weight=700, font, align='center', bevel=true, mat })` | 압출 글자. 한글이 있으면 Pretendard. 기준선 가운데가 원점 |
| `await model(url, { size })` | GLB(Draco·Meshopt). size = 가장 긴 변. 바닥이 y=0. `.clips`, `.pose(t, 이름)`(모델 안 애니메이션) |
| `set(obj, { pos, rot, scale })` | 위치·회전(라디안 [x,y,z])·스케일 한 번에 |
| `row(objs, { at=[0,0,0], gap=0.15, axis='x' })` | 폭대로 간격 둔 줄 자리 `[[x,y,z], ...]` |
| `pile(objs, { at=[0,0], radius, radiusTop, on, size, height, gap=0.04 })` | 그릇에 층층이 쌓을 자리 `[{ pos: [x,z], on, layer }]` → `land: { at, pos, on }` |
| `deg(d)` · `G` · `THREE` | 도→라디안, 실제 중력(단위/s², `M.drop`의 g로 쓸 때 `G * 1.6`), three.js |

단위: 폰 높이 3.04 = 실제 14.7cm (1단위 ≈ 4.8cm). 원기둥(위아래 반지름 같음)·상자는 물리에서 전용 모양으로 부딪힌다.

## API — 물리 `physics(W, { feel='snappy', gravity, walls })`

| 함수 | 설명 |
|---|---|
| `feel` | `snappy`(기본, 프로덕트) · `heavy`(큰 물체, 안 튐) · `floaty`(가벼운 소품) · `real` |
| `walls: { x: [x0, x1], z: [z0, z1] }` | 안 보이는 벽 (굴러 나가지 않게) |
| `sim.body(obj, { pos, rot, at, hold, vel, spin, land, bounce, friction, density, damp, upright, squash })` | 물리 물체. pos: `'above'`면 land 자리 바로 위 화면 밖에서 기다리고 놓기 직전까지 숨는다. at을 빼고 land만 주면 놓는 시각을 거꾸로 계산. hold(t) = 놓기 전 손으로 움직이는 경로(속도를 이어받음). damp = [공기, 구름 저항]. squash 기본 0.06 |
| `sim.kinematic(obj, (t) => ({ pos, rot }))` | 키프레임으로 움직이는 물체도 충돌에 참여 |
| `sim.bake(film.dur)` | 미리 굽기 (백그라운드, 같은 입력은 다시 안 굽는다). Stage.film 안에서 |
| `sim.apply(t)` | draw 맨 앞에서 |
| `sim.impacts` · `sim.notes` | 충돌 기록 `[{ t, name, speed }]`, 어색한 설정 안내 |

## 3D 검사 `node tools/render.mjs films/<이름> [--format 9x16] --check3d`

첫 줄 판정 → 문제마다 `→` 고칠 숫자 → `구도` 줄(비트별 여백 위/아래/왼/오 %, 카메라 숫자 제안, 글자·3D 겹침) → `물리 설정`·`비트` 줄. 그림(`check3d/views.png` 정면·옆·위, `motion.png` 높이·속도)은 숫자로 안 풀릴 때만.

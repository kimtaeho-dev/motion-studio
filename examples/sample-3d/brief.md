# sample-3d — 브리프

<inputs>
- 무엇: motion-studio 3D 데모. 결제 화면이 들어 있는 폰 목업 + 입체 글자 + 재질 도형
- 쓰이는 곳: 3D 쓰는 법의 기준 예시, 앱에 들어가는 샘플
- 길이 · 포맷: 8초 루프 · 1x1 (9x16, 16x9는 배치를 바꿔 같은 타임라인)
- 상태: 결제하기 버튼 → 로딩 → 체크 → 폰 회전·카메라 다가감 → 폰이 떠오르고 도형이 자리 바꿈 → 처음 자리
- 데이터/문구: 결제 · 주문 #2048 · 노트/펜 세트/스티커 · 합계 ₩48,000 · 결제하기 · Ship
- 색: 배경 #E9E6E0 · 폰 그래파이트 · 포인트 #2F6BFF · 서체 Pretendard(UI) + Geist(입체 글자)
- 3D: 폰 목업, 입체 글자, 도형 3개(플라스틱 캡슐, 진주 구, 클레이 링). 조명 studio
- 레퍼런스: 없음
</inputs>

# 레시피: 타이포그래피

제목, 타이틀 카드, 인용, 키네틱 타이포, 문구 리빌, 캡션, 손글씨·경로 리빌, 숫자. 공통 규칙과 `lottie.mjs text` 사용법은 `prompts/lottie.md`의 [글자](../lottie.md#글자).

## 기본

- 글자는 전부 `node tools/lottie.mjs text`로 만든 아웃라인 셰이프. 네이티브 텍스트(`ty:5`)는 BLOCK이고, 초안용으로도 쓰지 않는다(문구가 바뀌면 `text`를 다시 돌린다).
- 정확한 문구가 없을 때만 묻는다.
- 오버레이·제목 요소는 투명. 화면 전체 타이틀 카드면 `bg` 슬롯.
- 새로움보다 읽히는 위계. 위계·줄 구성·마지막 정지 프레임의 균형을 먼저 잡고 액센트는 나중.
- 서체: Pretendard(한글·제품) 또는 Geist(영문·제품). 디스플레이 1개 + UI 1개. 굵기·크기·간격으로 위계를 만든 뒤에 장식.

## 종류

| 종류 | 핵심 |
|---|---|
| 타이틀 카드 | 강한 마지막 정지 프레임, 분명한 위계, 절제된 리빌 |
| 인용 리빌 | 읽는 속도, 줄 리듬, 출처는 본문이 읽힌 뒤 |
| 에디토리얼 리빌 | 다듬은 줄바꿈, 크기 리빌, 여백 |
| 손글씨·경로 리빌 | 자연스러운 획 순서, 트림 타이밍, 잉크 멈춤 |
| 키네틱 타이포 | 의미에 묶인 안무. 단순한 등장이 아니다 |
| 글자 모핑 | 정점 구조가 같을 때만. 아니면 교체·크로스페이드·배치 변경 |

## 역할

- **앵커**: 구도를 붙잡는다. 가만히 있거나 조금만.
- **보조**: 맥락. 보통 더 조용하게.
- **액티브**: 주된 움직임을 진다. 키네틱이면 키프레임 전에 액티브 단어를 하나 이상 정한다.

## 키네틱 기준

- 최소 한 단어·구절이 의미에서 나온 위치·스케일·배치 변화·리듬·강조로 움직인다.
- 모든 단어에 같은 등장(슬라이드·페이드·스케일)을 주는 것은 키네틱이 아니다.
- 단어의 뜻이 움직임을 정한다: 떨어지다 → 낙하, 오르다 → 상승, 딱 → 날카로운 착지, 깨지다 → 분리, 흐르다 → 연속 이동, 부드럽게 → 느린 착지, 무겁다 → 낮게 묵직하게, 크게 → 확장, 조용히 → 물러남, 빠르게 → 짧은 타이밍, 천천히 → 긴 멈춤.
- 활발한 움직임과 정지 사이의 대비로 읽힘을 지킨다.

## 프리셋

`title-clean`(절제된 제목) · `editorial-reveal`(줄 단위 크기 리빌 + 살짝 착지) · `quote-lift`(줄 단위, 출처는 한 비트 뒤) · `kinetic-word-choreography`(액티브 단어가 배치·스케일·리듬을 이끎) · `statement-mask`(줄 단위 리빌, 강한 정지 위계) · `word-per-beat`(비트마다 한 단어, 마지막에 락업) · `typewriter-clean`(`h:1` 계단 리빌) · `handwritten-trace`(선 글자를 트림으로) · `numeric-pop`(숫자 카운트·착지, 라벨은 부드럽게).

## 타이밍과 이징 (60fps)

- 짧은 제목: 60~120f. 긴 인용: 90~180f.
- 등장은 ease-out(`.20,.75,.34,.94`), 보조는 `.00,.65,.51,.99`. 타자기는 계단. 넘침은 키네틱·장난스러운 스타일에만, 작게.
- 글자 엇갈림 2~4f, 단어 4~8f, 줄 8~14f. 읽는 순서대로.
- 엇갈림을 줄 때 불투명도는 위치·스케일보다 먼저 끝나게(가독성).

## 만들기

- 줄·단어 단위가 필요하면 줄(또는 단어)마다 `text`를 따로 돌려 레이어를 나눈다. 글자 단위는 `text`가 만든 글자 그룹(`nm` = 글자)의 `tr`에 키프레임.
- 줄 길이는 캔버스와 용도에 맞게 짧게. 줄바꿈은 의미 단위로, 우연처럼 보이지 않게.
- 줄 리빌은 마스크(WARN) 대신: 글자 그룹의 위치 + 불투명도, 또는 줄 위를 덮는 `rc`의 크기 키프레임(배경색이 단색일 때).
- 선·점·구분선·장식은 읽는 순서를 이끌거나, 글자를 드러내거나, 강조할 때만.
- 숫자 카운트는 자릿수마다 `h:1` 계단 키프레임으로 굽고, 자리마다 같은 폭 칸에 가운데 정렬해 자릿수가 흔들리지 않게.
- 문구는 슬롯으로 노출되지 않는다. 색만 슬롯(`--slot ink`).

## 흔한 실패

- 움직이는 중간에 안 읽힌다. 줄바꿈이 우연 같다.
- 마지막 프레임이 움직임보다 약하다.
- 손글씨가 자연스러운 획 방향과 반대로 그려진다.
- 키네틱이 균일한 단어별 등장일 뿐이다. 모든 단어가 똑같이 움직여 이끄는 구절이 없다.
- 장식이 공간만 채운다. 위계·줄바꿈이 정해지기 전에 효과가 들어온다.

## 통과 조건

- 첫·마지막 프레임이 깨끗한 정지 구도.
- 검사한 모든 프레임에서 읽힌다.
- 키네틱 요청엔 의미에서 나온 움직임의 액티브 단어가 있다.
- 크기가 다른 글줄은 대문자 높이 중심이 맞고, 쌓인 덩어리 간격이 일정하다(스틸 확대로 확인).
- 움직이는 동안 가장자리에 닿거나 잘리지 않는다.

# sample-morph — 브리프

<inputs>
- 무엇: motion-studio 데모. 채용 서비스 흐름을 하나의 도형으로 보여주는 UI 모핑 루프
- 쓰이는 곳: 팀 내부 데모, 레포 README
- 길이 · 포맷: 12초 루프 · 1x1 (9x16, 16x9 동일 타임라인)
- 상태: 버튼 → 로더 → 체크 → 알림 토글 → 탭 → 차트 → ⌘K 검색 → 토스트 → 버튼
- 데이터/문구: 지원하기 · 새 공고 알림 · 전체/개발/디자인 · 이번 주 지원자 +18% · 128명 · 디자이너 · 지원이 완료됐어요
- 색: 배경 #ECEAE5 · 잉크 #111111 · 종이 #FFFFFF · 포인트 #2F6BFF · 서체 Pretendard(UI) + Geist(키캡)
- 음악: 합성 (120BPM)
- 레퍼런스: 없음
</inputs>

<direction>
Dribbble 수준의 UI 모션. 하나의 도형, 컷 없음. 모든 상태는 같은 컨테이너가 크기·모서리·색을 바꾸고, 내용은 짧은 블러로 교체된다.
커서가 실제 클릭으로 변화를 일으킨다. 따뜻한 회색 배경, 흑백 컴포넌트 + 포인트 1색. 스프링, 오버슈트는 아주 살짝.
카메라가 줌해서 각 상태가 화면을 채운다. 마지막 프레임 = 첫 프레임.
금지: 통통 튀는 이징, 파티클, 글로우, UI 크롬 그라데이션, 죽은 구간.
</direction>

<structure>
120BPM, 6마디(24비트), 비트마다 무언가 일어난다. 상세는 shotlist.md.
</structure>

<gotchas>
내용은 도착할 크기 기준으로 배치하고 클립으로 드러낸다(모핑 중 찌그러짐 방지).
커서는 카메라 밖 화면 좌표로 그린다(줌과 무관하게 같은 크기).

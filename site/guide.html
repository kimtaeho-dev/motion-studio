설치하기

  1. 다운로드에서 설치 파일을 받아요. 2020년 말 이후에 산 맥이라면 대부분 Apple Silicon이에요. 잘 모르겠다면 화면 왼쪽 위 사과 메뉴 → 이 Mac에 관하여에서 칩 이름을 보세요. M1, M2처럼 M으로 시작하면 Apple Silicon, Intel이라고 적혀 있으면 Intel이에요.
  2. 받은 파일을 열고 Motion Studio 아이콘을 응용 프로그램 폴더로 끌어다 놓아요.
  3. 처음 열 때 "확인되지 않은 개발자"라는 안내가 나올 수 있어요. 시스템 설정 → 개인정보 보호 및 보안으로 가서 그래도 열기를 한 번만 눌러 주세요.
  4. 처음 실행하면 앱이 필요한 준비를 알아서 하고, Claude 계정으로 로그인하도록 안내해요. 따로 설치하거나 설정할 건 없어요.

앱에는 예시 작업 몇 개가 들어 있어요. 하나 열어서 재생해 보고, 오른쪽에서 색을 바꿔 보면 어떻게 쓰는지 금방 감이 와요.

00:04

무엇을 만들지 고르기

왼쪽 위 +를 누르면 어디에 쓰나요?를 먼저 물어봐요.

영상으로 올릴 것

SNS 게시물, 발표 자료, 출시 영상처럼 영상 파일로 쓸 때 골라요. 화면 비율(정사각 · 세로 · 가로 · 피드)과 길이를 정해요.

앱·웹에 넣을 것

로딩 표시, 완료 체크, 아이콘처럼 서비스 화면 안에서 움직일 걸 만들 때 골라요. 개발자에게 바로 넘길 수 있는 Lottie 파일로 나와요. 크기와 길이를 정해요.

얼마나 공들일지

영상은 AI가 완성본을 직접 보고 고치는 과정을 몇 번 거칠지 고를 수 있어요.

  • 빠르게: 한 번만 보고 고쳐요. 방향부터 빨리 보고 싶을 때 좋아요.
  • 기본: 세 번 보고 고쳐요. 대부분은 이걸로 충분해요.
  • 런칭용: 모든 항목이 충분히 좋아질 때까지 계속 고쳐요. 시간이 가장 오래 걸려요.

여기서 고른 비율과 길이는 AI가 마음대로 바꾸지 않아요. 다르게 하는 게 낫겠다 싶으면 먼저 물어봐요.

00:08

원하는 걸 말하기

오른쪽 아래 채팅창에 원하는 모션을 평소 말하듯 적어 주세요. 무엇이, 어떤 순서로, 몇 초 동안 움직이는지 알려 주면 가장 잘 알아들어요.

  • 버튼이 로딩을 거쳐 체크로 바뀌는 4초짜리 반복 영상. 포인트 컬러는 파랑
  • 앱 출시를 알리는 15초 세로 영상. 첫 화면 → 검색 → 결과 → 저장 순서로
  • 폰이 돌면서 결제 화면이 체크로 바뀌고, 옆에 'Ship'이 입체 글자로

정해지지 않은 게 있으면 AI가 먼저 물어봐요. 고민되면 "알아서 정해 줘"라고 해도 괜찮아요. 무엇으로 정했는지는 알려 드려요.

파일 같이 보내기

이미지, 영상, 로고, 3D 모델을 채팅창에 끌어다 놓을 수 있어요. 보낸 파일 옆에 붙은 표시를 눌러 어떻게 쓸지 골라 주세요.

참고용

"이런 느낌으로"를 전할 때 써요. 분위기, 색, 리듬만 참고하고 그림이나 로고는 가져오지 않아요. 다른 브랜드 영상의 캡처를 보낼 때 고르세요.

이미지와 영상은 처음에 참고용으로 들어가요.

그대로 쓰기

그 파일이 화면에 그대로 들어가요. 비슷하게 다시 그리지 않아요. 우리 로고, 아이콘, 서비스 화면 캡처, 제품 3D 모델을 보낼 때 고르세요.

SVG와 3D 모델은 처음에 그대로 쓰기로 들어가요.
  • AI는 우리 서비스 화면을 상상해서 그리지 않아요. 실제 화면이 나와야 하면 캡처를 그대로 쓰기로 보내 주세요.
  • 로고나 아이콘은 SVG로 주면 가장 좋아요. 크게 키워도 선명하고, 획이 하나씩 그려지는 것처럼 부분마다 따로 움직일 수 있어요. Figma에서 SVG로 내보내면 글자도 모양 그대로 들어가요.

Figma 링크 보내기

Figma에서 만든 화면을 그대로 움직이고 싶다면 링크를 보내 주세요. 레이어 위치, 문구, 이미지를 그대로 가져와요.

  1. 처음 한 번만, claude.ai 설정의 커넥터에서 Figma를 연결해요.
  2. Figma에서 움직이고 싶은 프레임을 오른쪽 클릭하고 선택 항목 링크 복사를 눌러요. 파일 전체 링크가 아니라 프레임 링크여야 해요.
  3. 채팅에 링크를 붙이고, 어떻게 움직이면 좋을지 함께 적어요.
내가 편집할 수 있는 파일만 가져올 수 있어요. 보기만 가능한 파일이라면 Figma에서 파일 이름 옆 메뉴 → 내 드래프트로 복제를 한 뒤 복제본의 링크를 보내 주세요. Figma 무료 요금제에서는 한 달에 가져올 수 있는 횟수가 정해져 있어요(20번 정도). 화면 하나에 최대 3번을 쓰고, 한 번 가져온 화면은 다시 불러오지 않아요.

음악에 맞추고 싶다면

영상에는 소리가 들어가지 않아요. 음악은 편집 프로그램에서 얹어 주세요. 쓸 곡이 정해져 있다면 곡의 빠르기(BPM)와 첫 박이 나오는 시간을 알려 주세요. 장면이 바뀌는 순간을 박자에 맞춰 드려요.

00:12

만들어지는 동안

AI가 지금 무엇을 하고 있는지 앱 오른쪽 위에 단계로 보여요. 내가 해야 할 건 질문에 답하기와 장면 계획 승인하기, 두 가지뿐이에요.

  1. 브리프무엇을 만들지 정리해요. 빠진 내용이 있으면 질문이 와요. 답해 주세요.
  2. 숏리스트장면 계획을 보여 드려요. 몇 초에 무엇이 나오고 어떻게 움직이는지 적은 표예요. 괜찮으면 승인을, 바꾸고 싶으면 채팅으로 말해 주세요. 승인하기 전에는 만들기 시작하지 않아요.
  3. 스틸 · 초안장면마다 한 장씩 뽑아 보고, 빠르게 한 번 돌려 봐요. 배치와 글자, 타이밍을 다듬는 단계예요.
  4. 검수완성본을 직접 보며 고쳐요. 글자가 잘 읽히는지, 멈춰 보이는 구간은 없는지 점수를 매기고 부족한 곳을 손봐요.
  5. 전달완성이에요. 재생해 보고, 더 고칠 게 있으면 말하거나 파일로 받으면 돼요.

영상을 뽑는 동안에는 플레이어 아래에 진행률이 보이고, 원하면 거기서 멈출 수 있어요.

앱·웹에 넣을 것은 더 빨라요

  • 아이콘이나 로딩 표시처럼 하나로 끝나는 애니메이션은 장면 계획 승인 없이 바로 만들어요.
  • 고칠 게 없으면 검수를 일찍 끝내요.
  • 개발자에게 넘기기 전에, 실제 웹과 앱에서도 똑같이 보이는지 비교해 보고 넘겨요.

다 만든 뒤에도 고칠 수 있어요

"로고가 조금 더 늦게 나오게", "마지막 문구를 더 크게"처럼 바꾸고 싶은 것만 말하면 그 부분을 고치고 다시 확인해요.

00:16

직접 손보기

문구 하나, 색 하나 바꾸는 건 AI를 기다릴 필요 없어요.

  • 속성: 문구, 색, 크기 같은 값을 바로 바꿔요. 전체 길이를 바꾸면 장면들이 같은 비율로 늘어나거나 줄어들어요.
  • 타임라인: 장면 표시를 끌어서 옮기면 움직임이 함께 따라와요. 박자에 딱 붙고, ⌥를 누른 채 끌면 더 세밀하게 옮길 수 있어요.
  • 내가 직접 바꾼 값은 AI가 몰래 되돌리지 않아요. 꼭 바꿔야 할 땐 먼저 이유를 말해요.

파일로 받기

플레이어 오른쪽 위 내보내기에서 원하는 형식을 골라요. 여러 개를 한 번에 골라도 돼요. 받은 파일은 다운로드 폴더 → Motion Studio에 작업별로 모여요.

형식이럴 때 골라요
MP4SNS에 올리거나 발표 자료에 넣을 때. 가장 무난해요.
GIF슬랙이나 노션에 바로 붙일 때.
ProRes 4444프리미어, 파이널 컷 같은 편집 프로그램에서 다른 영상 위에 얹을 때. 배경이 투명하게 나와요.
WebM웹페이지에 투명 배경 영상으로 넣을 때.
포스터·컨택트 시트썸네일로 쓸 대표 장면 한 장과, 장면들을 한눈에 모아 본 이미지가 필요할 때.
Lottie개발자에게 넘길 때. 앱·웹에 넣을 것으로 만든 작업에서만 보여요. 속성에서 바꾼 값이 그대로 담겨요.

배경을 투명하게 만든 작업을 MP4로 받으면, 투명한 부분이 바둑판 무늬로 채워져요. MP4는 투명 배경을 담을 수 없어서예요. 투명하게 쓰려면 ProRes 4444나 WebM을 골라 주세요.

00:24

막혔을 때

"이 필름을 열 수 없어요"라고 나와요
채팅에 "필름이 안 열려"라고 보내면 AI가 고쳐요.
"로그인이 풀렸어요"라고 나와요
다시 로그인을 누르고, 로그인이 끝나면 다시 보내기를 눌러요. 보냈던 메시지가 그대로 다시 가요.
영상 뽑는 데 오래 걸려요
12초짜리 정사각 영상이 30초 안팎 걸려요. 맥 사양에 따라 더 걸릴 수 있고, 플레이어 아래 진행률 옆에서 멈출 수 있어요.
Figma 링크를 못 읽어요
커넥터에 Figma가 연결돼 있는지, 내가 편집할 수 있는 파일인지 확인해 주세요. 이번 달 횟수를 다 썼다면 프레임을 PNG나 SVG로 내보내 채팅창에 끌어다 놓아도 돼요.
작업을 실수로 지웠어요
바로 사라지지 않아요. 작업 폴더 안의 .trash 폴더에 남아 있어요.

내 작업은 어디에 저장되나요?

맥 안에 저장되고, 앱을 업데이트해도 지워지지 않아요. Finder에서 직접 열어 보려면 이동 → 폴더로 이동(⇧⌘G)에 아래 주소를 붙여 넣으세요.

~/Library/Application Support/Motion Studio/workspace

그 밖에 막히는 곳이 있으면 GitHub에 남겨 주세요.
